
# BMI Calculator

## Internship
Oasis Infobyte - Python Programming

## Task
Task 2: BMI Calculator (Beginner)

## About the Project
This is a beginner-level BMI Calculator written in Python.
It asks the user for weight in kilograms and height in meters,
calculates BMI, and displays the corresponding category.

## Formula
BMI = weight / (height * height)

## BMI Categories
- Underweight: BMI below 18.5
- Normal weight: BMI from 18.5 to below 25
- Overweight: BMI from 25 to below 30
- Obese: BMI 30 or above

## Features
- Calculates BMI to two decimal places
- Displays the BMI category
- Validates weight and height
- Handles non-numeric input
- Allows repeated calculations

## Requirements
Python 3. No external libraries are required.

## How to Run
Run the following command in a terminal:

python bmi_calculator.py

## Testing
Tested with normal values, non-numeric input, non-positive weight,
and an unreasonable height value.
